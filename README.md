# Placement Portal Application V2 (PPA-V2)
**IITM BS Modern Application Development II - Capstone Project**

A production-grade Placement Portal connecting Students, Companies, and Admins. 
Features include ML-powered resume screening, asynchronous reporting, and PWA support.

## Tech Stack
- **Backend:** Flask, SQLAlchemy, Celery, Redis (`uv` managed)
- **Frontend:** Vue 3, Pinia, Bootstrap (`bun` managed)
<!-- - **DevOps:** Docker, GitHub Actions (CI/CD) -->
<!-- - **ML:** Scikit-learn (ATS Screening & Placement Prediction) -->
